Entry for make.fun's **One-Liner Laugh Lab** bounty: write one short funny
line answering a prompt — the excuse a robot vacuum gives after eating a sock.

## The line

> It looked like a dust bunny, it smelled like a dust bunny, and frankly, it tasted like a promotion.

The vacuum runs a deadpan sensor report — looked like a dust bunny, smelled
like a dust bunny — then turns it with a very human rationale: it tasted
like a promotion. It is not sorry; it thinks eating the sock earned it a
raise. Dust bunnies are literally what a vacuum is supposed to eat, so the
mistake is a believable machine error and the joke grows out of the vacuum's
own job. One sentence, 99 characters and 99 bytes as verified by running
the program, no setup that overstays.

## How to run

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (creating the directory if
needed), after validating it: 1–200 characters, a single line, UTF-8.
